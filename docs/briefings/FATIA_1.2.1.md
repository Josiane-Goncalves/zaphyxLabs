# ZAPHYX LABS — FATIA 1.2.1
## Design System

Status: Planejamento aprovado para análise pelo Codex.

### Contexto

A Zaphyx Labs desenvolve sites, landing pages e
automações para pequenos e médios negócios.

Nossa identidade visual é:

"Ideias em órbita. Negócios em movimento."

A marca combina sofisticação comercial, criatividade,
exploração espacial sutil e tecnologia.

### Referência visual

A referência oficial é a composição
"Zaphyx Labs — Ideias em órbita".

O Hero futuro apresentará um símbolo Z metálico
tridimensional, acompanhado por três módulos orbitais
que representam os serviços da empresa.

Não implementar esse Hero nesta fatia.

### Objetivo

Construir exclusivamente a fundação visual da aplicação.

### Escopo

1. Configurar Tailwind CSS 4 com Vite.
2. Centralizar tokens de cores.
3. Definir tipografia e hierarquia visual.
4. Definir padrões de espaçamento.
5. Configurar estilos globais.
6. Estabelecer padrões de acessibilidade.
7. Organizar os arquivos de estilo necessários.

### Paleta

Background: #0B1020
Text:       #F4F6FA
Primary:    #58DDE0
Accent:     #F4B860

Cores adicionais devem ser justificadas e derivadas
da identidade aprovada.

- Header definitivo.

- Objetos 3D.

Não modificar funcionalidades fora do escopo.

- Tailwind CSS funcionando.
- Tokens centralizados.
- Tipografia consistente.
- Estilos globais organizados.
- npm run lint sem erros.
- npm run build sem erros.
